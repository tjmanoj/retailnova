RetailNova turns every shopper conversation into a demand signal. A Gemini 3.8 Flash concierge (Google ADK, on Agent Platform) serves shoppers in English, Hinglish or Tamil, by text or photo, answering only from the real catalog and live store stock, with reserve and notify-me. Gemini Flash-Lite converts each chat into a structured signal, capturing unmet demand that sales data never sees. A manager's Demand Radar compares sales-only vs demand-sensed forecasts from BigQuery AI.FORECAST (TimesFM); an agent plans stock transfers and reorders with evidence, and one-click approval updates inventory and notifies waiting shoppers. Google stack: Cloud Run hosts the FastAPI + ADK agents with keyless service identity; Firebase Hosting serves the React UI and routes /api to Cloud Run; Firestore holds catalog, Gemini Embedding vectors (vector search), inventory and live signals with real-time listeners.
