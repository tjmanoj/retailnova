RetailNova turns every shopper conversation into a demand signal. A Gemini 3.6 Flash concierge (ADK on Agent Platform) serves shoppers by text, photo or voice note in English, Hindi or Tamil, answering only from the real catalog and live stock, with reserve (QR pass) or notify; Memory Bank remembers preferences. Flash-Lite turns each chat, and walk-ins logged by staff, into structured signals: the unmet demand sales data never sees. A Demand Radar compares sales-only vs demand-sensed BigQuery AI.FORECAST (TimesFM) forecasts; an agent plans transfers/reorders with Google Search trend evidence; one-click approval moves stock and notifies shoppers. Model Armor screens prompts. Cloud Run hosts the FastAPI + ADK agents (keyless); Firebase Hosting serves the React PWA and routes /api; Firestore holds catalog, vectors, inventory and live signals (real-time listeners). Measured: 32/33 eval cases, 100% grounded; backtest -11% lost revenue. No login. Synthetic data.
