RetailNova turns every shopper conversation into a demand signal. A Gemini 3.6 Flash concierge (Google ADK, Agent Platform) serves shoppers in English, Hinglish or Tamil, by text or photo, answering only from the real catalog and live store stock, with reserve/notify-me. Gemini Flash-Lite turns each chat into a structured signal, capturing unmet demand that sales data never sees. The manager's Demand Radar compares sales-only vs demand-sensed BigQuery AI.FORECAST (TimesFM) forecasts; an agent plans transfers/reorders with evidence; one-click approval updates stock and notifies waiting shoppers. Google stack: Cloud Run runs the FastAPI + ADK agents (keyless identity); Firebase Hosting serves the React UI and routes /api to Cloud Run; Firestore holds catalog, Gemini Embedding vectors (vector search), inventory and live signals (real-time listeners). Measured: 29/30 eval cases, 100% grounded products; backtest -11% lost revenue. No login. Try: "Diwali ke liye maroon silk saree, 5000 tak". Synthetic data.
